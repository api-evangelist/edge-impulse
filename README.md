Edge Impulse is the end-to-end edge AI MLOps platform for building datasets, training and optimizing machine learning models, and deploying them directly on device — from the smallest microcontrollers to gateways with the latest neural accelerators. The platform covers the whole workflow: sensor data collection and labeling, DSP feature engineering, model training with the EON Tuner and EON Compiler, hardware-aware profiling for latency, RAM and flash, and deployment as a C++ library, Arduino library, WebAssembly package, Docker container or prebuilt firmware. It is driven programmatically through three APIs — a 559-operation Studio API, an Ingestion API and a device Remote Management WebSocket — plus CLIs, Python/Node/Rust/Go SDKs and a first-party MCP server. Founded in 2019 by Zach Shelby and Jan Jongboom; acquired by Qualcomm Technologies in March 2025 and still operating under its own brand.

**Areas:** Artificial Intelligence · Machine Learning · Embedded Machine Learning · Edge AI · MLOps · Computer Vision · IoT · Model Deployment · Developer Tools · Real-Time · A2A

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Edge Impulse: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
